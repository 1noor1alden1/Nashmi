# Nashmi Economy — Intelligent Marketplace Edition

**النسخة المعدّلة وفق اتفاقات Smart Matching وAuto-Categorization والمناقصات بالنقاط.**

اقرأ أولًا `NASHMI-INTELLIGENT-RELEASE.md` الذي يحتوي جميع الملفات الجديدة، والميزات وحدودها، وأوامر التشغيل والاختبار، وكيفية ترحيل قاعدة البيانات بأمان. الملفات القديمة مثل `IMPLEMENTATION_REPORT.md` تصف حالة الأرشيف الأصلي قبل هذا الإصدار ولا تُعتبر مرجعًا للتغييرات الحديثة.

النسخة الأصلية التي أرسلها المستخدم لم تُمس؛ كل التعديلات داخل هذا المجلد المشتق.

**تنبيه:** يلزم تشغيل PostgreSQL وML وAPI والواجهة وتثبيت مكتبات Node. لم تُشغّل قاعدة بيانات متكاملة ضمن بيئة المراجعة. لا تنشر على الإنترنت أو تجمع بيانات طلبة حقيقية قبل اجتياز مراجعة الأمان والاختبارات المذكورة في دليل الإصدار.
